# Leaders

Leaders is an unofficial, independent digital adaptation of the Leaders board game, developed as a personal project for non-commercial purposes.

## About

Leaders brings the original board game experience to mobile: full game engine, puzzles, local player-vs-player matches, replay, and in-app rules.

## Features

| Section | Description |
|---|---|
| **Core engine** | Board, characters, actions, turn structure, and full game logic |
| **Puzzles** | Browse, solve, create, and share puzzles (official and custom) |
| **Player vs Player** | Local free-play matches on a single device |
| **Replay** | Review completed games turn by turn |
| **Rules** | In-app rules reference |
| **Settings** | Application preferences |

## Getting Started

The project targets Android (Java, View System, package `com.leaders`).

No public build is available yet. If you'd like to try an APK, reach out at **leaders.unofficial.app@gmail.com**.

## Project Management

Managed through GitHub Issues: one **milestone** per version, one **epic** per functional section, broken down into small **sub-issues** (native GitHub sub-issues), each delivered via its own small pull request.
