# GameLogic

This directory contains the technical documentation of the GameLogic module.

## Diagrams

- overview.mmd — High-level architecture
- packages.mmd — Package dependencies
- projection.mmd — Game state representation
- interaction.mmd — Interaction protocol
- resolution.mmd — Action resolution workflow
- board.mmd — Board representation

## Architecture Decision Records

Architectural decisions are documented independently in the `adr/` directory.

Each ADR describes one architectural decision and may supersede previous decisions as the engine evolves.
